遊戲即時字幕　使用說明
======================
English guide: see "User Guide (English).txt"

這是什麼
--------
把 Discord 或遊戲裡別人講的話，即時變成浮在畫面上的中英雙語字幕。
可以聽英文翻成中文，也可以聽中文翻成英文。


怎麼開始
--------
1. 把整個壓縮檔解壓縮（不要只拿出 exe，旁邊的 _internal 資料夾也要在）
2. 雙擊「遊戲即時字幕.exe」
3. 照視窗上的「使用步驟」操作，按「開始」


翻譯方向
--------
在「翻譯方向」選對方講的語言：
- 對方講英文 → 選「英文 → 中文」，字幕上面是英文、下面是中文翻譯
- 對方講中文 → 選「中文 → 英文」，字幕上面是中文、下面是英文翻譯
選錯的話會聽不出字，或變成亂碼。


畫面語言 Language
-----------------
視窗最上方右邊可以切換「繁體中文／English」，執行紀錄和字幕上的提示也會跟著換。
第一次打開時，Windows 是中文就顯示中文，其他語言的 Windows 會顯示英文。


只翻譯某一個程式（例如只翻 Discord）
------------------------------------
在「只翻譯這個程式」選 Discord.exe，遊戲角色講的英文就不會被翻譯，
只有 Discord 裡真人講的話才會變成字幕。

清單裡找不到的話：先讓那個程式發出一次聲音（例如請對方講一句話），
再按旁邊的「重新整理」。選了程式之後，「聲音來源」就用不到了，會自動變灰。


第一次使用
----------
- 第一次按「開始」可能要等 1～2 分鐘才有反應，這是 Windows 防毒在檢查檔案，
  不是當掉。第二次之後大約 3 秒就會開好。
- 語音辨識模型的「標準」已經內建在裡面，不用下載任何東西就能直接用。
- Windows 可能跳出「Windows 已保護您的電腦」：
  按「其他資訊」→「仍要執行」。
  （因為這個程式沒有花錢買數位簽章才會這樣，不是病毒）


顯示卡
------
- 有 NVIDIA 顯示卡會自動用顯示卡加速，速度快很多。
- 沒有的話會自動改用 CPU，一樣能用，只是字幕會慢 1～2 秒；
  這時「辨識準確度」請選「快速」或「標準」，不要選「精準」。


翻譯
----
- 預設用 Google 翻譯，不用任何設定。
- 想要比較口語的翻譯可以選 Gemini，但要自己到
  https://aistudio.google.com/apikey 申請免費金鑰，而且比較慢。


移動字幕、調整字幕大小
----------------------
- 用滑鼠直接把字幕條拖到任何位置。
- 拖右下角的握把「◢」可以調字幕條的寬度。
- 遊戲中也有效的快速鍵：
    Ctrl+Alt+方向鍵 → 移動字幕
    Ctrl+Alt+L      → 鎖定／解鎖（鎖定＝滑鼠穿透，不會擋到遊戲操作）
- 位置和寬度都會自動記住，下次打開就在同一個地方。


換辨識準確度（快速／精準）
--------------------------
「辨識準確度」只有「標準」是內建的。改選「快速」或「精準」時，
下面會出現「尚未下載」，按右邊的「下載」，等進度條跑完就可以用了。
- 「快速」約 140MB、「精準」約 1.5GB。網路慢的話「精準」可能要等半小時以上。
- 下載中可以按「取消」，已經下載的部分會留著，下次會從中斷的地方接續。
- 每個模型只要下載一次，之後就不用再等了。
- 忘了先下載就按「開始」也沒關係，程式會問你要不要現在下載。


常見問題
--------
- 看不到字幕 → 遊戲改成「無邊框視窗」，全螢幕獨佔模式看不到。
- 字幕一直亂跳、出現奇怪的字 → 把「音量門檻」調高。
- 別人講話都沒反應 → 「聲音來源」選對播放聲音的喇叭／耳機，或把「音量門檻」調低。
- 字幕聽不出字或變成亂碼 → 檢查「翻譯方向」是不是跟對方講的語言相符。
- 勾了「滑鼠穿透」之後關不掉字幕 → 回到啟動視窗按「停止」。
- 翻譯那一行一直顯示「—」 → Google 翻譯可能暫時連不上，可以改選 Gemini。
- 下載模型一直失敗 → 先確認網路正常，再按一次「下載」；
  用「標準」的話完全不用下載，可以先改回「標準」。
